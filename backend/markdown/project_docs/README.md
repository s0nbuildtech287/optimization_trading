# Bộ tài liệu kiểm thử LotusQuant

## Mục đích

Bộ tài liệu này giúp tester hiểu từng màn hình trước khi kiểm thử. Mỗi file mô tả công dụng, dữ liệu đầu vào, cách thao tác, công thức chính, kết quả mong đợi và các tình huống cần lưu ý.

## Trình tự đọc đề xuất

1. Đọc `00-thuat-ngu-va-cong-thuc.md` để thống nhất cách hiểu các chỉ số.
2. Kiểm tra đăng nhập và quyền truy cập.
3. Kiểm tra dữ liệu nguồn tại Backtest Tables, Strategies và Order List.
4. Kiểm tra bốn nhóm Dashboard.
