# Admin - Account Provisioning

## Công dụng

Cho admin tạo và quản lý tài khoản, role và thông tin user. Role user không được phép thực hiện các API quản trị.

## Cách dùng

1. Mở danh sách user.
2. Tạo user với username/email/role và thông tin bắt buộc.
3. Sửa thông tin hoặc role.
4. Xóa user khi đã đánh giá ownership dữ liệu và job liên quan.

## Lưu ý

Không dùng trang này để sửa trực tiếp dữ liệu nghiệp vụ. Mọi thay đổi role cần được ghi nhận và kiểm tra lại quyền API backend.
